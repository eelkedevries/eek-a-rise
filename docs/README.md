# docs

Documentation for users of eek-a-rise, safe to publish.

- `usage.md`: the two modes, the parameters and their sources, the downloads, and
  research use (presentation loops for PsychoPy and Psychtoolbox, gamma).
- `validation.md`: what the checks show, with numbers, and how to run them.
- `troubleshooting.md`: common problems.
- `installation.md`: working on the code locally.
- `deployment.md`: how the page reaches <https://eelkedevries.com/eek-a-rise/>.
